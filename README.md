# CareTrack Clinic - Tibbiy Yozuvlarni Boshqarish Tizimi

Ushbu loyiha `CareTrack Clinic` uchun zamonaviy `TYBT` web-ilovasi bo'lib, rolga asoslangan kirish nazorati, bemor profillari, shifokorlar, tashxislar va chiroyli dashboard interfeysini o'z ichiga oladi.

## Ishga tushirish

1. Terminalni `c:\Users\acer\Desktop\caretrack-clinicc` papkasiga oching.
2. `npm install` buyrug'ini bajarib, kerakli paketlarni o'rnating.
3. `npm start` bilan serverni ishga tushiring.
4. Brauzerda `http://localhost:4000` manzilini oching.
